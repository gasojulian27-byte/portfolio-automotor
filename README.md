# Portfolio personal

Portfolio web con temática de automovilismo y tecnología, desarrollado con HTML5 y CSS3.

## Archivos
- `index.html`: estructura y contenido.
- `css/estilos.css`: diseño y adaptación a pantallas pequeñas.
- `assets/img/`: carpeta para imágenes propias o autorizadas.
- `bitacora_ia.md`: registro del uso de IA.

## Antes de publicar
Reemplazar los textos entre corchetes, revisar que las descripciones reflejen trabajos reales, probar enlaces y revisar la vista en celular.

## Identidad visual automotriz
La página utiliza una imagen de portada creada para este portfolio, con Ferrari, BMW, Volkswagen, Porsche y un Volkswagen Scirocco destacado. La imagen está guardada en `assets/img/banner-automotor.png`.
